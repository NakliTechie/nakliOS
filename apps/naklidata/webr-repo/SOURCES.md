# R statistics pack: sources and licences

NakliData serves these WebAssembly builds of R packages from its own origin, so the R cell can install them without contacting another site. The binaries come from the webR project repository (repo.r-wasm.org, R 4.6) and are pinned by hash in `integrity.json`.

Most packages are under the GNU GPL or LGPL. The source for each version is available at the link in its row. For a version that ends in `.9000`, the webR project built a patched development version; its source is in the webR project repository on GitHub (github.com/r-wasm).
