          AI providers
          
    
          
      Lorewell can run a private model entirely in this browser. NakliOS AI
      remains the first choice when the app is hosted. An OpenAI-compatible
      endpoint is an optional fallback.
    
          
    
          
      
          
        
          
          Built in · Gemma 4 E2B
          
            Transformers.js 4.2 · WebGPU · about 3.4 GB, cached locally
          
        
          
        
        
      
          
      
      
      
      
          
        No book text is uploaded. Model files are downloaded from Hugging Face.
      
          
      
          
        
        
      
          
      
          
        Technical details
        
      
          
    
          
    
          Endpoint or BYOK
          
    
          
      The endpoint and model stay in this browser. The API key is session-only
      and is never written into a book, library export, or log.
    
          
    
          
      
      
      
    
          
    
          
      Ollama and LM Studio expose OpenAI-compatible APIs. Start the local
      server, allow CORS for this Lorewell origin, then test the connection.
    
          
    
          
      
      
    
          
    
          
      
      
    
          
    
          
      
      
      
    
          
    
          
      
      
    
          
    
    
    
          AI is optional. Reading and local lexical search do not depend on it.
          
    
          
      
      
      
    
          
  
          
          


  
          
    
          Ask from your sources
